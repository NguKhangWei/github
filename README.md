# github

A practice repository for building Git skills, based on FIT2109 Week 4–5
material and the Week 7–8 in-class Git demonstration (branching, merging,
and conflict resolution).

`shop.py` is a tiny, deliberately trivial "bike rental shop" script — a
stand-in for the real demonstration repo's `store.py`. There is nothing to
learn about the code itself; it just holds a few constants, a `RATES`
dict, a `FLEET` dict, and a couple of small functions.

Run it with:

```
python3 shop.py
```

## Usage

```
python3 shop.py --help
```

## How to use this repo

See [TASKS.md](TASKS.md) for a numbered set of exercises, roughly in the
order you should attempt them. Do them for real — create the branches,
trigger the conflicts, read the diffs — rather than just reading the
steps. Nothing here is checked automatically; the point is the reps.
